# 💼 Подработки — учёт смен и расчёт зарплаты

Простое PWA-приложение для учёта подработок, отгулов и отпусков с автоматическим расчётом зарплаты.

Работает полностью офлайн. Данные хранятся только на устройстве пользователя, без регистрации и сервера.

## Возможности

- Журнал подработок, отгулов и отпусков.
- Расчёт оплаты с коэффициентами для будней, выходных и праздников.
- Расчёт отпускных.
- Производственный календарь РФ.
- Архив выплат по месяцам.
- Экспорт и импорт резервной копии в JSON.
- Установка на телефон как приложение.

## Установка

Откройте основное приложение:

**https://licspit.github.io/Podrabotki/**

### Android

В Chrome или Edge откройте меню и выберите «Добавить на главный экран» или «Установить приложение».

### iPhone и iPad

Откройте приложение в Safari, нажмите «Поделиться» → «На экран Домой» → «Добавить».

При обновлении приложения существующие записи, праздники и настройки сохраняются на устройстве.
